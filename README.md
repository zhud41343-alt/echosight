# 听见光影 EchoSight — 视障感官替代 3D 空间声场引擎

> **2026 Qoder 高校创造力大赛 · Hack4Good 技术向善赛道参赛作品**（同时可扩展用于挑战杯、中国国际大学生创新大赛、计算机设计大赛等赛事）

## 核心创新
基于神经科学 **感官替代理论（Sensory Substitution）**，在纯浏览器端实现了 **实时计算机视觉（Rec.709 灰度化 + Sobel 3×3 边缘梯度提取）**、**端侧多模态 AI 语义识别（TensorFlow.js COCO-SSD + 离线拓扑兜底）** 与 **Web Audio 3D HRTF 双耳头部相关传输函数空间音频合成** 的跨模态映射引擎：
- 水平位置 $X \to$ 3D HRTF 双耳方位角（$-68^\circ \sim +68^\circ$）
- 垂直高度 $Y \to$ 音调频率（支持五声音阶 / 半音阶 / 经典 vOICe 对数频谱）
- 边缘强度与亮度 $\to$ 声波响度与多通道和声合成
- 端侧物体识别 $\to$ 中文空间方位与距离实时标注 + 自动语音播报

## 四大交互模块
1. **实时声画扫描仪**：支持实时摄像头、本地图片上传及 4 类内置程序化场景；提供原始画面 / Sobel 边缘热力图 / 48×16 声学矩阵三视图切换、点击/拖动任意坐标的**交互式点探声场**、实时 FFT 频谱与空间障碍物拓扑 HUD、端侧 TensorFlow.js COCO-SSD 语义识别与自动语音播报，以及算法参数热调台。
2. **指尖听画板**：在发光画布上自由涂鸦即可实时听见每一笔的 3D 空间位置与音高（附带实时方位角与音高 HUD），支持音阶切换、笔触粗细、回放速率调节、多步撤销、PNG 导出及整幅画作的声波扫描回放。
3. **黑暗迷宫 · 3D 回声定位挑战**：内置 3 个递进难度关卡，开启「视障全黑模式」，通过 8 方向实时射线追踪（Raycast）+ 3D HRTF 墙壁距离延迟回声、出口和弦信标、无障碍语音方位提示与通关最佳步数/计时记录，10 秒让健全人切身共情“听声辨位”。
4. **原理与技术路线**：完整展示跨模态数学映射公式、端侧 AI 流水线及“Web 原型 → 端侧 WebGPU 深度估计 → AR 眼镜+骨传导耳机”演进路线。

## 快捷操作与无障碍支持
- 顶部导航栏内置 **「弱视高对比」** 一键切换（WCAG AAA 纯黑底 + 高饱和黄大字模式，自动记忆偏好）与 **「耳机校准」**（播放左 → 中 → 右 3D HRTF 校准音）。
- 支持数字键 `1`–`4` 快速切换四大模块；在声画扫描仪中按 `Space` 启停扫描；在黑暗迷宫中使用方向键 / `WASD` 移动、`Space` 发射 3D 声呐脉冲。
- 关键状态接入 `aria-live` 实时朗读与 Web Speech 中文语音播报。
