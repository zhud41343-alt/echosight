# 技术局限、风险与隐私边界说明（SAFETY_AND_LIMITATIONS）

## 1. 产品定位声明
**听见光影 EchoSight 是浏览器端跨模态辅助感知与感官替代研究原型，不是经过安全认证的医疗器械或成熟户外导航产品。**
- 不可替代白手杖、导盲犬、定向行走（O&M）训练或现场交通安全判断。
- 严禁依赖本系统进行独立过马路或高风险户外道路通行决策。

## 2. 已知技术局限与验证状态

| 模块 | 当前真实能力 | 已知局限与风险 | 验证状态 |
| :--- | :--- | :--- | :--- |
| **端侧物体识别（COCO-SSD）** | 浏览器本地 WebGL 识别 80 类常见物体 | 对玻璃门、路面坑洼、细小障碍、暗光与强逆光存在漏检；未检出绝不代表前方无障碍 | 已实现，真实街道准确率待实测 |
| **单目距离估算** | 提供可配置相机标定接口与输入有效性检查 | 未标定手机仅输出粗略区间；物体被遮挡、倾斜或非标准高度会导致显著误差 | 仅有合成基准模拟测试，真实距离误差待实测 |
| **环境异常声响提示** | 单路麦克风检测突发高能量频谱突变 | 单麦克风无法确定声源方向（非 360° 定位），强风/人群喧哗可能产生误报 | 仅有离线合成样本评测 |
| **信号灯框内颜色识别** | 多帧稳定器 + 过曝/多灯混合拒识 | 无法区分机动车灯与人行横道灯、无法确认与当前通行方向相关性，不输出过街建议 | 仅有像素模拟用例验证 |
| **Web 后台与离线能力** | 提供 `manifest.json` 支持「添加到主屏幕」安装；监听 `visibilitychange` 后台进入 `UNAVAILABLE` | 当前**未配置 Service Worker**，仅支持桌面安装、不支持断网离线打开；浏览器安全策略限制锁屏后台摄像头采集 | 已如实披露边界 |
| **端侧模型网络依赖** | COCO-SSD 权重首次加载后在内存运行，支持网络恢复后重试加载 | 默认权重托管于外部 CDN，国内无加速网络环境可能下载缓慢或失败（失败时 EchoSafe 诚实进入 `DEGRADED`） | 已实现重试与降级 |
| **语音识别隐私边界** | 调用浏览器原生 Web Speech Recognition | 视觉推理与音频合成 100% 本地完成；但多数浏览器的语音识别会将音频发往浏览器厂商云端转写 | 已在界面与文档如实披露 |
| **高对比显示模式** | 纯黑底 + 纯白字 + 高饱和黄信号色 + 放大字号 | 尚未完成全部 WCAG 2.2 AAA 成功准则与真实 VoiceOver/TalkBack 全流程审计，故不宣称 AAA 认证 | 已实现，真实手机读屏待实测 |
| **触觉振动与屏幕常亮** | 事件驱动触觉（确认/近距/失效）与会话绑定 Screen Wake Lock | `navigator.vibrate` 在 iOS Safari 不支持；Screen Wake Lock 属尽力申请、低电量会被系统释放，不等于后台采集能力 | 已实现优雅降级与自动化测试 |
