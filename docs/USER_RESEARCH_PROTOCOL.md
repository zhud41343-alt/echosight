# 真实视障用户受控环境共创研究方案（USER_RESEARCH_PROTOCOL）

> **声明**：本文件为待执行的伦理合规用户研究方案。当前项目尚未开展真实视障用户实地试验，下表所有实测数据栏位均保持空白，绝不编造用户评价。

## 1. 研究伦理与安全前提
- **研究环境**：仅在受控室内走廊/实验室安全场地开展，全程由定向行走（O&M）指导人员或明眼安全员陪同。
- **严禁事项**：严禁要求受试者放弃白手杖或导盲犬，严禁在无传统助行方式保护下进入真实机动车道。
- **知情同意与隐私**：向受试者以语音/盲文/大字形式完整告知系统原型局限及浏览器语音识别可能的云端转写行为，录音与日志去标识化存储，受试者可随时无条件退出。

## 2. 受试者分组计划
- **A 组（完全失明、长期使用 VoiceOver / TalkBack 用户）**：计划招募 3–5 名。
- **B 组（低视力/弱视、依赖放大与高对比度用户）**：计划招募 3–5 名。

## 3. 受控测试任务清单
1. 独立通过读屏找到并理解「随身助行」模式与风险说明。
2. 完成摄像头/麦克风授权并确认是否理解当前 EchoSafe 状态反馈。
3. 分别体验 4 种听觉提示策略（简洁语音优先 / 低频空间提示 / 按需描述 / 实验性连续声场），评估听觉负担。
4. 触发语音查询与模拟语音识别失败场景，评估替代操作可用性。
5. 独立完成暂停、切后台恢复后的自检提示理解与退出流程。
